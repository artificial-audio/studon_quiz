# Quiz: Linear Algebra Basics

type: mcq-sa
title: Matrix–Vector Multiplication

## Question
**Question:**  
What is the result of the matrix–vector multiplication  
$$
y = Ax
$$
where $$A$$ is a constant matrix?

### Options
- [ ] 0  
- [x] A linear transformation of $$x$$  
- [ ] $$x^2$$  
- [ ] A constant scalar  

### Feedback
The product $$Ax$$ represents a linear transformation applied to the vector $$x$$.
